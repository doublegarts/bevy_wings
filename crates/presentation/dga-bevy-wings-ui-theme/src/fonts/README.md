# Inter

`Inter-Variable.ttf` is the unmodified upright variable Inter font (`wght`, `opsz`) from
[Google Fonts](https://github.com/google/fonts/tree/0b58fb370093f9a9f4ff785d94405710b79de67c/ofl/inter).
Upstream filename: `Inter[opsz,wght].ttf`.

Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter).
Redistributed under the SIL Open Font License 1.1; the complete license is in `OFL.txt`.
The font is embedded into the theme crate and installed at Bevy's default font asset ID.
